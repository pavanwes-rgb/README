# Atualização do Site de Venda de Cosméticos Puriflora

## **Descrição**

A atualização do site da Puriflora foi necessária porque a versão anterior já não acompanhava a nova identidade visual da empresa. Com isso, a comunicação do site deixou de estar alinhada com o posicionamento e a imagem atual da marca.

Para iniciar o projeto, realizamos o mapeamento da jornada do usuário, buscando entender melhor todo o processo de navegação e compra dentro do site. Esse levantamento foi importante para identificar pontos de melhoria na experiência do usuário e tornar a navegação mais clara, intuitiva e eficiente.

Fiquei responsável pelo desenvolvimento do protótipo do novo site, já seguindo a nova identidade visual da marca. Durante esse processo, utilizei principalmente Adobe Photoshop, Adobe Illustrator e Figma para a criação dos elementos visuais, organização das telas e desenvolvimento do protótipo.

Após a finalização do protótipo, o projeto foi apresentado ao coordenador para validação. Com a aprovação, iniciamos a etapa de desenvolvimento do site, ficando meu amigo Eike responsável pela implementação e construção das páginas.

#**Tecnologias utilizadas**

- Adobe Photoshop
- Adobe Illustrator
- Figma
- HTML
- CSS
- JavaScript

Essas tecnologias foram utilizadas para estruturar, estilizar e implementar as interações e funcionalidades do novo site.
